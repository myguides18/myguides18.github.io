速通攻略专题攻略专题

Speedrun Guide

速通（Speedrun）是以最快速度完成游戏为目标的高级玩法。本专题汇集了多款热门游戏的最优速通路线、跳关技巧和世界纪录参考，帮助追求效率的玩家突破极限。

攻略内容

一、速通基础入门

速通（Speedrun）是指玩家以最快速度完成游戏或达成特定目标的挑战方式。速通社区是全球游戏文化的重要组成部分，每年有GDQ（Games Done Quick）等大型速通慈善活动。 【速通分类】 - Any%：以任意方式通关，不限制收集和完成度。 - 100%：完成游戏所有内容后通关。 - Glitchless：不使用任何Bug和漏洞。 - Low%：以最低完成度通关。 - 全BOSS：击败所有BOSS后通关。 【速通工具】 - LiveSplit：计时器软件，记录分段时间和对比最佳成绩。 - OBS Studio：录制和直播软件。 - 模拟器/帧数工具：用于精确操作和Bug复现。

二、艾尔登法环速通路线

【Any% 速通路线（世界纪录约55分钟）】 1. 开局选择「武士」职业，跳过教程直接进入宁姆格福。 2. 直奔风暴山丘获取「猎犬步伐」战灰。 3. 使用「飞马Bug」跳过史东薇尔城，直接到达利耶尼亚。 4. 获取「陨石杖」和「岩石球」法术，作为主要输出手段。 5. 击败满月女王→碎星拉塔恩→恶兆王蒙葛特→火焰巨人→黑剑玛利喀斯→初始之王葛孚雷→艾尔登之兽。 6. 关键跳关：使用「Zip」Bug（精确位置传送）跳过大量区域。 【关键技巧】 - 飞马Bug：在特定位置召唤灵马并同时使用特定动作，可以飞出地图边界。 - Zip：在特定帧输入精确操作，实现超远距离传送。 - 无敌帧利用：翻滚和战技的无敌帧躲避BOSS攻击。

三、黑神话悟空速通路线

【Any% 速通路线（世界纪录约2小时30分钟）】 1. 第一章：直奔广智获取变身，跳过白衣秀士（非必打），击败黑熊精。 2. 第二章：获取定风珠，击败黄风大圣。使用「蓄力棍」跳过部分小怪区域。 3. 第三章：击败亢金龙→魔将妙音→黄眉大王。利用「筋斗云」快速移动。 4. 第四章：击败紫蛛儿→百眼魔君。使用「避毒丹」降低毒伤。 5. 第五章：击败红孩儿→牛魔王。利用「避火罩」降低火伤。 6. 第六章：击败二郎神（隐藏）→大圣残躯，触发真结局。 【关键技巧】 - 蓄力棍跳关：满蓄力重击可以跳过部分触发战斗的区域。 - 变身取消后摇：变身后立即取消可以重置动作。 - 定身术最大化输出：在BOSS出招前摇时定身，获得最长输出窗口。

四、其他游戏速通参考

【塞尔达传说：王国之泪 Any%】 世界纪录约50分钟。核心策略：初始空岛获取能力后，直接使用「火箭盾」+「左纳乌装置」飞往海拉鲁城堡，利用「弹簧盾」跳过大量解谜，直奔最终BOSS加侬多夫。 【博德之门3 Any%】 世界纪录约3分钟（使用Bug）。正常速通约1小时：使用盖尔的「自爆」结局跳过第三章全部内容。 【星露谷物语 社区中心完成%】 世界纪录约3小时。核心策略：利用「代码名Bug」刷物品，精确规划每天行程，优先完成季节性收集包。 【CS2 竞速通关（Surf/Bhop地图）】 Surf和Bhop是CS2的移动技巧，速通玩家在自定义地图中挑战最快完成时间。需要数千小时的练习才能达到顶级水平。

五、速通社区与资源

【速通记录查询】 - speedrun.com：全球最大的速通记录数据库，支持按游戏、分类、平台筛选。 - 各游戏Discord速通频道：获取最新路线和技巧。 【速通活动】 - GDQ（Games Done Quick）：每年两次的大型速通慈善活动，全球速通玩家聚集展示。 - ESA（European Speedrunner Assembly）：欧洲速通聚会。 【入门建议】 1. 选择你最喜欢的游戏开始，热情是坚持的动力。 2. 先观看世界纪录视频，学习路线和技巧。 3. 从简单分类开始（如Any%），逐步挑战更难分类。 4. 加入速通社区，向有经验的玩家请教。
